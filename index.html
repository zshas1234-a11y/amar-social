Firebase & Vercel Setup Guide

Step-by-step instructions for AMAR SOCIAL HUB PRO

Firebase Authentication Setup

1. Go to the Firebase Console for project amar-d755e.
2. Navigate to Build > Authentication > Click Get Started.
3. Enable the Email/Password provider.
4. Go to Users tab > Click Add User > Create admin user with email zainbalochkhan00@gmail.com and your secure password.

Firestore Database & Security Rules

1. Go to Build > Firestore Database > Click Create Database.
2. Set rules in the Rules tab to allow public read and authenticated write: 

rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /services/{document} {
      allow read: if true;
      allow write: if request.auth != null;
    }
    match /settings/{document} {
      allow read: if true;
      allow write: if request.auth != null;
    }
  }
}

Deploying to Vercel

1. Save this single-file HTML code as index.html.
2. Create a GitHub repository and upload index.html (along with a basic vercel.json if needed).
3. Go to Vercel Dashboard > Click Add New > Project > Import your repository.
4. Click Deploy. Vercel will instantly host your static single-page app!
